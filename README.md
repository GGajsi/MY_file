# 📁 EZ폴더 (EZ Folder)
> 소중한 개인 파일과 폴더를 안전하고 손쉽게 보호할 수 있는 파이썬 기반 폴더 잠금 프로그램입니다.

<!-- 💡 여기에 프로그램 실행 화면 스크린샷을 넣어주세요 (예: 깃허브 이슈에 이미지를 드래그 앤 드롭한 후 링크 복사) 💡 -->

## 📌 주요 기능
* **🔒 안전한 폴더 잠금**: 중요한 데이터가 들어있는 폴더를 외부 접근으로부터 안전하게 보호합니다.
* **🔓 손쉬운 잠금 및 해제**: 복잡한 과정 없이, 직관적이고 간편하게 폴더를 잠그고 원할 때 바로 해제할 수 있습니다.
* **🌍 4개 국어 지원**: 한국어를 포함한 총 4가지 언어 환경을 제공하여 누구나 편리하게 사용할 수 있습니다.

## 🛠 기술 스택
* **언어 (Language)**: Python
